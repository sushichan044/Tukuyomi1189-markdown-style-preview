# markdown-style-preview

同人誌の版下（版面）をブラウザだけでプレビューできるツールです。独自の軽量記法で原稿を書くと、右側に実寸に近い版面（ページ数・文字数・図版のDPIなど）がリアルタイムに表示されます。サーバーもビルドも不要な単一HTMLファイルです。

## デモ

**https://tukuyomi1189.github.io/markdown-style-preview/**

上記URLを開くだけですぐに使えます。

## 主な機能

- **版面プレビュー**
  - 判型（B5・A5・B6・文庫・A4）、天地左右の余白、文字サイズ・行送りを指定して、実際のページ数・1行あたりの文字数・1ページあたりの行数を確認できます。
  - 横組み／縦組みを切り替え可能。縦組みではルビ・傍点・段組みも版面どおりに表示されます。
- **軽量な原稿記法**（Markdown風。カッコ内は執筆ガイドライン準拠の別記法）
  - `##`〜`####` … 見出し（3段階。`#` や `#####`以降はガイドライン違反として警告）
  - `---` … 改頁
  - `![説明](fig1)` … 画像の挿入（貼り付け・ドラッグ＆ドロップで取り込み、`{60%}` で表示幅を指定。**プレビュー上の画像をクリックする**か、画像の行にカーソルを置いてツールバーの「表示幅」ボタンを押すと、数値入力だけで設定できます）
  - `![説明](images/xxx.png)` … 相対パス・URLの画像をそのまま参照（取り込み不要でプレビューできる。※Web版では使用不可。下記「注意事項」参照）
  - `\| A \| B \|` の表記 … 表（2行目を `\| --- \| --- \|` にすると罫線になる。直前に `[表: 説明]` でキャプション）
  - `\|漢字《かんじ》` / `{漢字|かんじ}` … ルビ（2つの記法に対応）
  - `《《傍点》》` … 傍点
  - `**強調**` … ゴシック体強調 / `*強調*` … 斜体
  - `> 引用` … 引用ブロック
  - `1. 項目` … 番号付きリスト（連続する行をまとめる）
  - `` `code` `` / `` ```lang〜``` `` … インラインコード／コードブロック（言語ラベル表示のみ、シンタックスハイライトはなし）
  - `$x^2$` / `$$〜$$` … インライン数式／ブロック数式（見た目を区別して表示するのみで、LaTeXとしての組版はしません）
  - `本文[^1]` と `[^1]: 注記` … 脚注（参照箇所には上付き番号、定義箇所には注記を表示）
  - `:::note[ラベル]〜:::` … 注意・補足の四角枠
  - `:::column[タイトル]〜:::` … コラムの囲み
  - `:::balloon[名前]〜:::` … アイコン付きの吹き出し（名前は `かぐや`／`ヤチヨ`／`彩葉` の3種、アイコン画像は `images/icons/`）
- **図版のDPIチェック**：挿入した画像が印刷解像度（300dpi）を下回ると警告表示。
- **執筆ガイドライン準拠チェック**：プレビュー画面右下に検証パネルを表示し、以下を自動チェックします。
  - 見出しレベル違反（`#` や `#####`以降の使用）
  - 吹き出しのキャラクター名が規定の3人以外
  - 画像パスが `images/ペンネーム_fig番号.拡張子` 形式でない（`images/` 直下でない・拡張子がない・ファイル名がガイドラインの命名規則でない場合に警告）
  - 分量が上限（2万字）を超過
  - 問題なければ「✓ 問題なし」、問題があれば件数と内容を一覧表示します。
- **自動保存**：ブラウザのIndexedDBに原稿・画像・設定を自動保存し、再読み込みしても復元されます（`file://` で開いた場合はローカルサーバー経由での起動が必要、という警告が表示されます）。
- **書き出し**
  - 対応ブラウザでは File System Access API による直接上書き保存（Ctrl+S）。
  - `.md` / 記法を除いた `.txt` としてダウンロード。
  - 原稿と図版一式をフォルダにまとめて書き出し（画像参照を `./img/` に自動置換）。

## 注意事項

- **相対パス・URL指定の画像（`![説明](images/xxx.png)` 形式）、および吹き出しのキャラクターアイコン（`images/icons/`）は、Web版（デモURL）では表示できません。** これらのパスは「開いている `index.html` の場所から見た相対パス」として解決されますが、Web版が配信しているのはツール本体（`index.html`）のみで、`images/` フォルダそのものは含まれていないためです。この形式を使う場合は、`index.html` を画像フォルダと同じ階層に置いてローカルで開いてください。
- 貼り付け・ドラッグ＆ドロップで取り込む画像（`![説明](fig1)` 形式）はブラウザのIndexedDBに保存されるため、Web版でも問題なく利用できます。
- 数式・コードブロックは版面上での見た目を区別するための表示に留まり、LaTeXの組版やシンタックスハイライトは行いません。
- 執筆ガイドライン準拠チェックは記法上のルール（見出しレベル・キャラクター名・画像ファイル名・分量）のみを対象とし、内容面のルール（盗用・生成AIの直接使用・R-18・「いらすとや」使用など）は自動判定できないため、各自での確認が必要です。

## 使い方

1. デモURLを開く（または `index.html` を直接ブラウザで開く）。
2. 左側のエディタに原稿を記法で入力する（初回はサンプル原稿が入っています）。
3. ヘッダーで判型・余白・文字サイズなどを調整する。
4. 右側のプレビューでページ数や版面を確認し、必要に応じて書き出しメニューから保存する。

## ローカルで動かす

`images/` フォルダを使った相対パス画像・吹き出しアイコンの表示や、`Ctrl+S`／「上書き保存」「名前を付けて保存」（File System Access API）を使うには、`index.html` をローカルサーバー経由で開く必要があります。

1. `index.html`（またはこのツールの元ファイル）を、`images/` フォルダと同じディレクトリに置く。
2. そのディレクトリで簡易サーバーを起動する。

   ```
   python3 -m http.server 8000
   ```

3. サーバーを起動した **その同じPC** のブラウザで `http://localhost:8000/` を開く。

### `file://` や他マシンのIPアドレスでは一部機能が使えません

- `file://` で直接ファイルを開くと、IndexedDBが使えず原稿が自動保存されません（画面上部に警告が表示されます）。
- `http://192.168.x.x:8000/` のように、同じネットワーク上の**別マシンのIPアドレス**経由でアクセスすると、ブラウザのセキュリティ制限（Secure Contextとして扱われない）により、`Ctrl+S`・「上書き保存」・「名前を付けて保存」のボタン自体が非表示になります。`.md`／`.txt`のダウンロードや画像・アイコンの表示は、この場合でも問題なく使えます。
- 直接保存の機能まで使いたい場合は、サーバーを起動しているPC自身で `localhost`（または `127.0.0.1`）経由で開いてください。

## 技術的な特徴

- 依存ライブラリなし、ビルド工程なしの単一HTMLファイル（`index.html`）。
- 原稿・画像・設定はすべてブラウザのIndexedDBに保存され、外部サーバーへは送信されません。
