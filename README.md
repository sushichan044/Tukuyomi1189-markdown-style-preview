# markdown-style-preview

同人誌の版下（版面）をブラウザだけでプレビューできるツールです。独自の軽量記法で原稿を書くと、右側に実寸に近い版面（ページ数・文字数・図版のDPIなど）がリアルタイムに表示されます。サーバーもビルドも不要な単一HTMLファイルです。

## デモ

**https://tukuyomi1189.github.io/markdown-style-preview/**

上記URLを開くだけですぐに使えます。

## 主な機能

- **版面プレビュー**
  - 判型（B5・A5・B6・文庫・A4）、天地左右の余白、文字サイズ・行送りを指定して、実際のページ数・1行あたりの文字数・1ページあたりの行数を確認できます。
  - 横組み／縦組みを切り替え可能。縦組みではルビ・傍点・段組みも版面どおりに表示されます。
- **軽量な原稿記法**（Markdown風）
  - `#`〜`######` … 見出し（6段階）
  - `---` … 改頁
  - `![説明](fig1)` … 画像の挿入（貼り付け・ドラッグ＆ドロップで取り込み、`{60%}` で表示幅を指定）
  - `\| A \| B \|` の表記 … 表（2行目を `\| --- \| --- \|` にすると罫線になる。直前に `[表: 説明]` でキャプション）
  - `\|漢字《かんじ》` … ルビ
  - `《《傍点》》` … 傍点
  - `**強調**` … ゴシック体強調
  - `> 引用` … 引用ブロック
- **図版のDPIチェック**：挿入した画像が印刷解像度（300dpi）を下回ると警告表示。
- **自動保存**：ブラウザのIndexedDBに原稿・画像・設定を自動保存し、再読み込みしても復元されます（`file://` で開いた場合はローカルサーバー経由での起動が必要、という警告が表示されます）。
- **書き出し**
  - 対応ブラウザでは File System Access API による直接上書き保存（Ctrl+S）。
  - `.md` / 記法を除いた `.txt` としてダウンロード。
  - 原稿と図版一式をフォルダにまとめて書き出し（画像参照を `./img/` に自動置換）。

## 使い方

1. デモURLを開く（または `index.html` を直接ブラウザで開く）。
2. 左側のエディタに原稿を記法で入力する（初回はサンプル原稿が入っています）。
3. ヘッダーで判型・余白・文字サイズなどを調整する。
4. 右側のプレビューでページ数や版面を確認し、必要に応じて書き出しメニューから保存する。

## 技術的な特徴

- 依存ライブラリなし、ビルド工程なしの単一HTMLファイル（`index.html`）。
- 原稿・画像・設定はすべてブラウザのIndexedDBに保存され、外部サーバーへは送信されません。
